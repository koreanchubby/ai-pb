# 계산 재현 예시 (데모 고객)

> 화면(app.js)이 내는 숫자를 손으로 다시 계산한 기록입니다. 같은 공식을 Python으로 따로 구현한 `scripts/calc_reference.py`가 **소수점 아래까지 똑같은 값**을 내는지 `tests/test_calc_reference.py`(9개)가 확인합니다.
> 기준: 2026-10-04, app.js = PR #7 + 보완 커밋 + 리포트 PDF + `fix/assumptions`(기대수익·변동성은 공개 CMA 결합값, 설문 구간 ≤19/≤28/≤36/≤45). 공식 설명과 근거는 `docs/FUNCTIONS.md`.

## 0. 입력값 (앱 기본값 + 설문은 데모 응답)

설문 응답의 기본값은 비어 있습니다. 아래 점수는 앱의 데모 응답 `DEMO_ANSWERS = [4, 3, 3, 2, 3, 0, 2, 2, 2, 2]`(선택지 번호, 0부터)를 고른 경우입니다.

| 항목 | 값 |
|---|---|
| 연령 · 상태 | 62세 · 은퇴 예정 |
| 가족 | 배우자 1, 자녀 2 · 희망 배분 40 / 35 / 25% |
| 목표 | 은퇴·승계 모두, 월 생활비 500만원, 연금 280만원 |
| 자산(억원) | 부동산 25, 국내 ETF 4, 해외 ETF 6, 국채 3, 회사채 2, 사모펀드 4, 대체 2, 현금 4, 부채 3 |
| 설정 | 하우스뷰 조정(TAA) 끔, 허용범위 밴드 켬, 재원 방식 "금융자산 준비" |

## 1. 투자성향

- 나이 점수: 62세 → 60~69세 구간 **2점**
- 설문 10문항 점수: 5 + 4 + 4 + 3 + 4 + 1 + 3 + 3 + 3 + 3 = **33점**
- 합계 **35점** → 29~36 구간 → 설문 성향 **3 (위험중립형)**
- 손실 감내 문항 "−10% 이내" = 3 → min(3, 3) = **위험중립형**
- 배분 비율: 주식 55% · 채권 32% · 대체 10% · 현금 3%, 주식 한도 50%

## 2. 은퇴 버킷

- 월 부족액 = 500 − 280 = **220만원**
- 비상자금 = 500 × 6개월 = 3,000만원 = **0.3억**
- 버킷 1(현금성) = 220 × 24개월 + 0.3억 = 0.528억 + 0.3억 = **0.828억**
- 버킷 2(채권) = 220 × 60개월 = **1.32억**

## 3. 상속세 추정

- 금융자산 = 4 + 6 + 3 + 2 + 4 + 2 + 4 = **25억**, 총자산 = 25 + 25 = 50억, 순자산 = 50 − 3 = **47억**
- 법정상속분: 배우자 1.5 / 3.5 = **42.86%**, 자녀 각 1 / 3.5 = 28.57% · 유류분은 그 절반(21.43%, 14.29%)
- 일괄공제 **5억**
- 배우자공제 = max(5, min(실제 47 × 40% = 18.8, 법정 47 × 42.86% = 20.14, 30)) = **18.8억**
- 금융재산공제: 금융자산 1억 초과 → min(2억, 25 × 20%) = **2억**
- 과세표준 = 47 − 5 − 18.8 − 2 = **21.2억** → 10억 초과 30억 이하 구간
- 산출세액 = 21.2 × 40% − 1.6 = 6.88억 → 신고세액공제 3% 적용 6.88 × 0.97 = 6.6736 → **6.7억**
- 재원 방식 "금융자산 준비"(계수 1), 보험 재원 0 → 채권으로 준비할 재원 **6.7억**

## 4. 포트폴리오 설계

| 단계 | 계산 | 결과(억원) |
|---|---|---|
| 투자 가능액 | 금융자산 25 − 사모펀드 4 | **21** |
| 현금 바닥 | 버킷 1 | **0.828** |
| 채권 바닥 | 버킷 2 1.32 + 상속세 재원 6.7 | **8.02** |
| 성장 풀 | 21 − 0.828 − 8.02 | **12.152** |
| 주식 | 12.152 × 55% = 6.6836 → 국내 30% 2.005, 해외 70% 4.6785 | **2.0 / 4.7** |
| 국채 | 8.02 + 12.152 × 32% × ½ = 8.02 + 1.944 | **10.0** |
| 회사채 | 12.152 × 32% × ½ | **1.9** |
| 대체 | 12.152 × 10% | **1.2** |
| 사모펀드 | 환매 전 고정 | **4** |
| 현금(SAA) | 25 − (2 + 4.7 + 10 + 1.9 + 1.2 + 4) | **1.2** |

**허용범위 밴드(0.3억)**: 회사채 목표 1.9와 현재 2의 차이 0.1억 < 0.3억 → 거래 생략, 2로 둠.

| 자산 | 현재 | 최종 목표 | 거래 |
|---|---|---|---|
| 국내 ETF | 4 | 2.0 | −2.0 |
| 해외 ETF | 6 | 4.7 | −1.3 |
| 국채 | 3 | 10.0 | +7.0 |
| 회사채 | 2 | 2 | 0 (밴드) |
| 대체 | 2 | 1.2 | −0.8 |
| 사모펀드 | 4 | 4 | 0 |
| 현금 | 4 | **1.1** | 순매수 2.9를 현금에서 (4 − 2.9) |

- 회전율 = (2 + 1.3 + 7 + 0 + 0.8 + 0 + 2.9) ÷ 2 = **7.0억** (금융자산의 28%)
- 주식 비중: 현재 40% → 목표 (2 + 4.7) ÷ 25 = **26.8%** — 위험중립형 한도 50% 이내

## 5. 위험·수익 (현재 데모 가정)

- 현재 기대수익 = 0.16×5.9 + 0.24×6.2 + 0.12×4.0 + 0.08×5.0 + 0.08×6.5 + 0.16×10.0 + 0.16×2.6 = **5.848%**
- 목표 기대수익 = (2×5.9 + 4.7×6.2 + 10×4.0 + 2×5.0 + 1.2×6.5 + 4×10.0 + 1.1×2.6) ÷ 25 = **5.664%**
- 변동성 √(Σ wᵢwⱼσᵢσⱼρᵢⱼ): 현재 **10.39%** → 목표 **8.09%** (상관계수 표는 FUNCTIONS 5절, 국채–주식 0)
- 스트레스 손실: 현재 −17.48% → 목표 −12.04%

## 6. 금융소득 (종합과세 기준 연 2,000만원)

- 현재 = 4×2.0% + 6×1.5% + 3×3.0% + 2×4.0% + 2×2.0% + 4×3.0% = 0.5억 = **5,000만원** → 기준 초과
- 목표 = 2×2.0% + 4.7×1.5% + (기존 국채 3×3.0% + 신규 7×저쿠폰 1.5%) + 2×4.0% + 1.2×2.0% + 1.1×3.0% = 0.4425억 = **4,425만원**
- 아직 기준 초과 → 화면은 연금계좌·분리과세 수단을 함께 제시
