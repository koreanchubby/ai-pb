## 1. 예측 (무엇을 맞히나)

| 항목 | 내용 |
|---|---|
| 예측 대상 | **다음 달 S&P 500 지수 월간 수익률이 0보다 큰가** (상승=1, 하락=0) |
| 예측 시점 | 매달 말 기준(실행은 다음 달 2일) |
| 출력 | 상승 확률 `p_up`(0~1)과 신호: 0.55 이상 "상승 우위", 0.45 이하 "하락 우위", 그 사이 "중립" |
| 앱에서의 역할 | 하우스뷰·시장근거 화면의 **참고 근거 하나**. 목표 배분·비중 숫자는 정하지 않음 (`PROJECT_BRIEF.md` 4장: AI는 비중 숫자를 정하지 않는다) |
| 왜 이 주제인가 | 우리 앱의 고객 포트폴리오에서 해외 주식 ETF 비중이 가장 크고, 하우스뷰 TAA(전술적 조정)가 "주식을 조금 늘릴지/줄일지"를 판단하는 구조라 같은 질문에 대한 데이터 근거가 됨 |

## 2. 데이터셋

| 시리즈 (FRED id) | 내용 | 특징값으로 쓰는 법 |
|---|---|---|
| SP500 | S&P 500 지수 (일별) | 1·3·12개월 로그수익률(`r1`·`r3`·`r12`), 라벨 |
| DGS10 | 미국 10년 국채금리 | 수준(`dgs10`), 1개월 변화(`d_dgs10`) |
| DGS3MO | 미국 3개월 국채금리 | 1개월 변화(`d_tb3`), 백테스트의 현금 수익률 |
| T10Y2Y | 장단기 금리차(10년-2년) | 수준(`t10y2y`) |
| DCOILWTICO | WTI 유가 | 1개월 로그수익률(`oil_r1`) |
| DEXKOUS | 원/달러 환율 | 1개월 변화율(`fx_r1`) |

- **출처**: FRED(St. Louis Fed) 공개 CSV, 키 불필요. 요청 사이 5초 이상, 오류 시 60초 뒤 1회만 재시도, 같은 날 받은 파일은 재사용.
- **월말 값**: 각 달의 마지막 관측값. 휴일·결측(".")은 건너뜀. **진행 중인 달은 버림**(월말 값이 아니므로).
- **기간**: FRED가 SP500을 최근 10년만 제공 → 2017-10 ~ 2026-09, **108개월**(12개월 모멘텀 계산에 앞 1년 사용).
- **저작권**: S&P 500 지수는 S&P Dow Jones Indices 저작물이라 **원자료는 저장소에 올리지 않음**(`data/raw/`는 `.gitignore`). 저장소에는 가공된 지표·예측만 남김.

## 3. 라벨링

- `label_t = 1 if SP500[t+1 월말] / SP500[t 월말] − 1 > 0 else 0`
- **미래 정보 차단**: 특징은 t월 말까지의 값만, 라벨은 t+1월 값으로 만든다. 마지막 달(결과 미확정)은 라벨 없이 "최신 예측" 입력으로만 쓴다.
- 기간 중 상승 비율: 약 59% (백테스트 구간 기준) → **"항상 상승이라고 찍기"가 강한 비교 기준**이 된다.
- 테스트로 확인: 라벨이 다음 달 수익률과 일치, 마지막 행 라벨 없음, 진행 중인 달 제외, 특징이 과거 값만 사용.

## 4. 모델과 백테스트

| 항목 | 설정 (재현용) |
|---|---|
| 모델 | 로지스틱 회귀 + L2 규제(λ=1.0, 절편 제외), 뉴턴법(IRLS) 최대 25회 |
| 표준화 | **학습 구간의 평균·표준편차로만** (테스트 구간 정보가 새지 않게) |
| 구현 | 표준 라이브러리만 (`LIBRARIES.md` 외부 라이브러리 0개 원칙) |
| 백테스트 방식 | **walk-forward(확장 창)**: 첫 48개월로 학습 → 다음 달 예측 → 한 달 늘려 다시 학습… |
| 매매 규칙(평가용) | `p_up > 0.5`면 다음 달 S&P 500 보유, 아니면 현금(3개월 금리/12) |
| 거래비용 | 주식↔현금 전환 1회당 0.1% |
| 비교 기준 | ① 항상 상승이라고 찍기 ② 학습 구간 다수 클래스 ③ 계속 보유(buy & hold) |
| 테스트로 확인 | i번째 예측은 i 이후 라벨을 바꿔도 변하지 않음(미래 정보 미사용), 계속 보유 수익률 계산 일치 |

## 5. 검증 결과 (2026-10-07 실행)

**전체 백테스트 59개월 (2021-10 ~ 2026-08)**

| 지표 | AI 모델 | 비교 기준 |
|---|---|---|
| 방향 정확도 | 50.8% | 항상 상승 59.3% · 다수 클래스 59.3% |
| AUC (0.5 = 무작위) | 0.444 | — |
| Brier 점수 (낮을수록 좋음) | 0.297 | — |
| 주식 보유 개월 | 46 / 59 | 59 / 59 |
| 연 수익률 | 8.9% | 계속 보유 10.9% |
| 연 변동성 | 13.1% | 15.5% |
| 샤프 비율 | 0.42 | 0.49 |
| **최대 낙폭** | **−14.8%** | −24.8% |

**최근 24개월 (2024-09 ~ 2026-08)**: 정확도 58.3%(항상 상승 54.2%), AUC 0.545, 연 수익률 15.4%(계속 보유 15.2%), 샤프 0.87(0.86).

**해석 (있는 그대로)**
- 이 모델은 전체 구간에서 **"항상 상승"보다 방향을 못 맞췄고**(AUC < 0.5), 수익률·샤프도 계속 보유보다 낮았다. 월간 주가 방향은 이 거시지표들만으로는 예측하기 어렵다는 뜻이다. (관련 학술 연구와의 비교는 서지 확인 후 추가 — 확인 필요)
- 장점은 **하락장 노출 축소**: 하락 위험 신호가 있던 달에 현금으로 빠져 최대 낙폭이 약 10%p 작았다.
- 최근 24개월은 기준보다 약간 나았지만 표본이 24개라 우연과 구분하기 어렵다.
- 따라서 이 신호는 **"주식 비중 조정의 근거"가 아니라 "참고 신호"**로만 쓰고, 화면에도 성과 한계를 함께 표시한다.

## 7. 한계와 개선 후보

| 한계 | 개선 후보 |
|---|---|
| 표본이 작음(108개월, SP500 10년 제공 제한) | 장기 무료 지수(예: 다른 공개 지수)로 기간 확장 검토 — 저작권 확인 필요 |

| 상승 비율이 높은 기간 | 임계값 0.5 대신 학습 구간 상승 비율 기준 비교 |
