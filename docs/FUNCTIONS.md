## 2. 고객 성향 (적합성)

### `surveyScore()`
- 입력: 나이(`#age`), 설문 10문항 응답(`state.answers`)
- 출력: `{score, declared, loss}`
- 로직: 나이 점수(40세 미만 5 … 70세 이상 1) + 문항 점수 합계 → 20 이하 1, 28 이하 2, 37 이하 3, 45 이하 4, 그 이상 5. 손실 감내 문항 값은 `loss`로 따로 보관.
- 근거: **[법령]** 금융소비자보호법 제17조(적합성 원칙) — 투자 목적·재산 상황·투자 경험 확인 의무. **[실무]** 금융투자협회 표준 투자자정보확인서 문항 구성. **[논문]** Grable & Lytton (1999), *Financial Services Review* 8(3), 163–181 — 다문항 위험성향 측정 도구. **[실무]** 구간 경계(20/28/37/45)는 표준 예시·키움증권의 100점 기준 20/40/60/80을 원점수 11~54로 선형 환산한 값(19.6/28.2/36.8/45.4)과 거의 같음 → 권고안 ≤19/≤28/≤36/≤45 (`docs/RESEARCH_PARAMETERS.md` C절).

### `getProfile()`
- 출력: 성향 1~5와 배분 비율(`PROFILES[level].mix`), 주식 한도(`equityCap`)
- 로직: `min(설문 성향, 손실 감내 응답)` — 둘 중 **더 보수적인 쪽**을 채택.
- 근거: **[실무]** 손실 감내 응답에 따른 강제 하향 — 하나은행 투자권유준칙 별지 제2호(2026-01-01 시행: 원금보존 → 안정형, 10% 이내 → 위험중립형 이하), 표준 예시 제5조제3항(혼합 방식 하향). 우리 규칙은 −5% 응답도 안정추구형으로 내려 약간 더 보수적. **[데모 가정]** 성향별 mix 비율.

## 3. 목표 설계

### `retirementBuckets()`
- 입력: 월 생활비, 월 연금(만원), 은퇴까지 연수, 고용 상태
- 출력: `{spend, gap, years, emergency, bucket1, bucket2, reserve}` — `spend`·`gap`은 만원/월, 나머지 버킷은 억원. `years`(은퇴까지 연수)는 표시용이며 계산식에는 쓰이지 않음
- 로직: 부족액 `gap = 생활비 − 연금`. 비상자금 = 생활비 6개월. 버킷1(현금성) = 부족액 24개월 + 비상자금. 버킷2(채권) = 부족액 60개월.
- 근거: **[논문]** 현금 리저브(버킷) 전략 — Pfeiffer, Salter & Evensky (2013), *Journal of Financial Planning* 26(9), 49–55: 현금 리저브를 두면 세금·거래비용이 있을 때 30년 생존율이 최대 6%p 높음. 목표별 층위 구조 — Shefrin & Statman (2000), *JFQA* 35(2), 127–151. 인출률 — Bengen (1994), *Journal of Financial Planning* (1994년 10월).
- 반론(함께 제시): Estrada (2018/2019, SSRN·IESE 워킹페이퍼) — 21개국 115년 자료에서 정적 배분+리밸런싱이 버킷보다 우월. → 버킷은 **고객의 심리적 안정(행동재무)** 목적이라고 설명한다.
- **[데모 가정]** 24·60개월 기간.

## 4. 승계 사전진단

### `legalWeights()` / `buildHeirs(useLegalDefaults)`
- 로직: 배우자 1.5, 자녀 각 1 → 법정상속분(%) 계산. 유류분 = 법정상속분 ÷ 2. 기본 배분은 법정상속분 또는 데모값(40/35/25).
- 근거: **[법령]** 민법 제1009조(법정상속분, 배우자 5할 가산), 제1112조(직계비속·배우자 유류분 = 법정상속분의 1/2. 형제자매 유류분은 헌법재판소 2024-04-25 위헌 결정 후 2024년 개정으로 삭제 — 앱은 배우자·자녀만 다루므로 영향 없음).

### `inheritanceTaxRate(base)`
- 입력: 과세표준(억원) / 출력: 산출세액(억원)
- 로직: 1억 이하 10%, 5억 이하 20%(누진공제 0.1억), 10억 이하 30%(0.6억), 30억 이하 40%(1.6억), 초과 50%(4.6억).
- 근거: **[법령]** 상속세 및 증여세법 제26조. 2026-10-04 기준 현행 유지 확인 — 2026-08-03 정부 세제개편안도 가업상속공제 위주로 일반 세율·공제 변경 없음(이투데이 2026-08-03 등). 유산취득세 전환은 국회 기재위 조세소위에서 보류(조세금융신문 2025-11-25), 도입 무산·최고세율 50% 유지(자유기업원 칼럼 2026-02-26). **매년 세법개정 반영 여부 재확인 필요.**

### `estimateEstateTax(net, financial)`
- 입력: 순자산, 금융자산(억원) / 출력: `{lump, spouseDeduction, financialDeduction, base, tax}`
- 로직: 일괄공제 5억, 배우자공제 = max(5억, min(실제 상속분, 법정상속분, 30억)), 금융재산공제(2천만 이하 전액 / 1억 이하 2천만 / 초과 20%·최대 2억) 차감 → 세율 적용 → 신고세액공제 3%(×0.97).
- 근거: **[법령]** 상증법 제21조(일괄공제), 제19조(배우자공제), 제22조(금융재산상속공제), 제69조(신고세액공제). 단순화: 기초공제·인적공제 중 일괄공제만, 사전증여 합산·부동산 평가는 반영 안 함 → **화면에 "추정치, 세무사 확인 필요" 표시 필수**.

### `estateReserve()`
- 로직: 상속세 목표액 × (연부연납이면 0.3, 아니면 1) − 보험 재원.
- 근거: **[법령]** 상증법 제71조(연부연납, 상속세 최대 10년 분할). **[데모 가정]** 0.3(첫 납부·초기 분납분 비율).

### `analyzeDistribution(showMessage)`
- 로직: 배분 합계 100% 확인 → 유류분 미달자 있으면 "법률 검토 높음", 법정상속분 75% 미만이면 "보통", 아니면 "낮음". 부동산이 절반 넘으면 공동소유 경고.
- 근거: **[법령]** 민법 제1115조(유류분의 보전 — 2026-03-17 시행 개정으로 금전 가액반환이 원칙, 2026-03-17 이후 개시된 상속부터 적용). **[데모 가정]** 75% 기준.

## 5. 포트폴리오 설계

### `computePlan()` — 핵심
- 입력: 자산(`getAssets()`), 성향, 은퇴 버킷, 상속세 재원, `state.useTaa`, `state.useBand`
- 출력: 현재·목표 보유액, SAA, 거래, 위험·수익·금융소득 비교 등을 담은 `plan` 객체
- 단계:
  1. **필수 안정자산(바닥)**: 현금 바닥 = 버킷1(은퇴 목표 없으면 비상자금), 채권 바닥 = 버킷2 + 상속세 재원. 투자 가능액보다 크면 비율로 축소.
  2. **조정 불가 자산 고정**: 사모펀드는 환매 전까지 그대로.
  3. **성장 풀 배분(SAA)**: 나머지를 성향별 mix로 주식(국내 30 : 해외 70)·채권(국채·회사채 반반)·대체·현금 배분.
  4. **하우스뷰 조정(TAA)**: 켜져 있으면 금융자산의 2%를 해외 주식에서 국채·현금성으로 반반 이동.
  5. **허용범위 밴드**: 목표와 현재 차이가 0.3억 미만이면 거래하지 않고 현금으로 정산.
- 근거: **[논문]** 목표 기반·정신적 회계 계층 구조 — Shefrin & Statman (2000), *Journal of Financial and Quantitative Analysis* 35(2) 행동 포트폴리오 이론. 장기 배분(SAA)이 수익 **변동**의 93.6%를 설명(수익률의 93.6%가 아님) — Brinson, Hood & Beebower (1986), *Financial Analysts Journal* 42(4). 기관 견해를 기준 배분에 소폭 반영 — Black & Litterman (1992), *Financial Analysts Journal* 48(5). 밴드 리밸런싱 — Masters (2003), *Journal of Portfolio Management* 29(3); Donohue & Yip (2003), *JPM* 29(4), 49–63; Jaconetti, Kinniry & Zilbering (2010), Vanguard Research "Best Practices for Portfolio Rebalancing"(연 1회·반기 점검 + 5% 임계치 권고). 여러 기관 전망 동일가중 결합 — Timmermann (2006), *Handbook of Economic Forecasting* Vol.1 Ch.4, 135–196 (주 근거), Bates & Granger (1969), *Operational Research Quarterly* 20(4), 451–468 (보조). **[데모 가정]** TAA 2%, 밴드 0.3억, 국내:해외 30:70.

### `portfolioStats(h)`
- 출력: `{vol, ret, stress, equityPct}`
- 로직: 자산별 가정 변동성·상관계수로 분산 = ΣΣ wᵢwⱼσᵢσⱼρᵢⱼ, 기대수익·스트레스 손실은 가중평균.
- 근거: **[논문]** Markowitz (1952), *Journal of Finance* 7(1). **[데모 가정]** `ASSUMPTIONS`의 변동성·수익률·스트레스 값과 상관계수(ETF끼리 0.8, 그 밖의 위험자산끼리 0.5, 국채–주식 ETF −0.2, 국채–회사채·대체·사모 +0.2, 현금–모든 자산 0).
- 교체 후보: 공개 장기 자본시장 가정(J.P. Morgan 2026 LTCMA, 2025-10-20 발표 등 3~4곳) 평균값 → `docs/RESEARCH_PARAMETERS.md`. 참고로 JPM 2026 기준 미국 대형주–미 중기국채 상관은 −0.01로, 현재 가정 −0.2보다 0에 가깝다.

### `financialIncome(holdings, currentGovbond, lowCoupon)`
- 로직: 자산별 과세 분배율 합계. 새로 사는 국채는 저쿠폰(1.5%)으로 계산해 금융소득을 낮춤. 결과를 연 2,000만원 기준과 비교.
- 근거: **[법령]** 소득세법 제14조 제3항 제6호(이자·배당소득 합계 2,000만원 이하는 분리과세, 초과 시 종합과세). **[실무]** 저쿠폰 채권 활용. **[데모 가정]** 분배율.

| `resetAppState()` / `addResetButton()` | 확인 후 예약된 저장을 취소하고 저장값 삭제·새로고침 ("처음부터 다시") |

## 7. 뉴스 수집 (`scripts/fetch_news.py`)

| 함수 | 하는 일 |
|---|---|
| `fetch_fed` / `parse_rss` | 연준 통화정책 보도자료 RSS(`press_monetary.xml`) → 공식(official) 항목 |
| `fetch_gdelt` / `parse_gdelt` | GDELT 5개 분류 검색(최근 24시간, 호출 사이 6초 대기) → 뉴스 항목. 한 분류가 막혀도 나머지는 유지 |

| `fetch_fred` / `parse_fred` | 미 10년물 금리·WTI → 시장지표 항목 (키 없으면 건너뜀, 지표별 실패 격리) |
| `classify(text)` | 영문 키워드는 단어 단위로만 일치(software의 war 같은 오분류 방지), 한글은 부분 일치 |
| `classify(text)` | 키워드로 금리·환율·유가·ETF·반도체·지정학 분류 |
| `importance(item)` | 출처 가중치(공식3·시장2·뉴스1)×2 + 분류 수(최대 2) + 큰 변동 2점, 최대 10 |
| `dedupe(items)` | 같은 URL·비슷한 제목 제거 |
| `merge_with_previous()` | 이전 AI 설명 유지, 보관 기간(뉴스·지표 72시간, 공식 14일) 지난 항목 삭제, 같은 지표는 최신값으로 교체 |
| `build()` / `main()` | 출처 하나가 실패해도 나머지로 `data/news.json` 생성. 전부 실패 시 종료 코드 1 |
| `redact(text)` | 오류 메시지에 섞인 API 키를 `***`로 가림 (공개 파일 유출 방지) |
| `same_content(new, old)` | 수집 시각만 다르면 파일을 다시 쓰지 않음 → 불필요한 봇 커밋 방지 |
| `merge_with_previous()` | 이전 AI 설명 유지, 보관 기간(뉴스 72시간·시장 지표 7일·공식 14일), 깨진 이전 항목 무시, 합친 뒤 한 번 더 중복 제거 |

- 근거: **[논문]** 뉴스 논조가 시장에 영향 — Tetlock (2007), *Journal of Finance* 62(3). **[실무]** 중요도 점수·보관 기간은 실무 기준(논문 근거 아님, DECISIONS 2026-10-03).

## 8. AI 설명 (`scripts/summarize_news.py`)

| 함수 | 하는 일 |
|---|---|
| `build_user_prompt(item)` | 제목·출처·수치만 `<data>`로 감싸 넣은 질문 생성(원문 본문 미사용, 제목 속 지시문은 따르지 않도록 지시) |

| `validate(result)` | 5칸 모두 있음, 각 220자 이하(프롬프트는 200자 요청), 매매 권유·명령형("매수하세요", "매수 적기", "비중 확대를 권합니다", "20% 늘리세요" 등)을 정규식으로 차단 — 사실 서술("수출이 10% 늘었다")은 허용 |

- 5칸: 확인된 사실 / AI 해석 / 내 자산 영향 / 반대 근거 / 판단 변경 조건 (가이드 6.2).

## 9-1. 리포트 PDF 저장 (`printReport()`, `print.css`)

- 두 번 눌러도 한 번만 실행되고, 아이폰 홈 화면 앱에서는 "Safari에서 열어 공유 → 프린트" 안내를 띄움.
- 하는 일: 리포트 화면으로 이동·최신 계산 반영 → 머리글(작성 시각, 승인 전이면 "전문가 승인 전 초안") 삽입 → 문서 제목을 `AI-PB-리포트-YYYYMMDD`로 바꿔 PDF 기본 파일 이름 지정 → `window.print()` → 인쇄 후 제목 복구.
- `print.css`: 화면에서는 인쇄용 머리글만 숨기고, 인쇄할 때(@media print) 메뉴·상단·단계 표시·하단 버튼을 숨겨 리포트만 A4로, 카드가 페이지 중간에서 잘리지 않게.
- 근거: **[실무]** 상담 기록 보관(금융소비자보호법 제17조의 확인 내용 제공 의무를 위한 출력물). 외부 라이브러리 없이 브라우저 기능 사용.

## 9-2. 뉴스 화면 연결 (`news-view.js`) *(시안 — 팀원 검토 후 채택)*

| 함수 | 하는 일 |
|---|---|
| `load()` | `data/news.json`을 캐시 없이 읽음. 실패·빈 목록이면 아무것도 바꾸지 않음(데모 카드 유지) |

| `formatTime()` / `formatDay()` | 한국시간. 뉴스는 오늘이면 HH:MM, 아니면 M/D HH:MM. 시장 지표는 시각 대신 기준일(M/D 기준), 금리 변화는 %p |
