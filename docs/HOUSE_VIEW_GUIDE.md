# 하우스뷰 월간 입력 방법

> 매월 초 1회, 참고 증권사들의 월간 하우스뷰를 점수로 옮겨 적는 방법입니다. **핸드폰 브라우저로도 할 수 있습니다.**
> 계산 규칙: `scripts/house_view.py` · 결정 기록: DECISIONS 2026-09-30

## 1. 규칙 (먼저 읽기)

- 증권사 자료의 **문장·표·차트는 옮기지 않습니다.** 자산군별 의견을 숫자 하나로만 적습니다: 확대 `1` · 중립 `0` · 축소 `-1`.
- "소폭 확대", "비중 확대 유지"처럼 표현이 달라도 방향만 봅니다: 늘리자는 쪽이면 `1`, 줄이자는 쪽이면 `-1`, 유지면 `0`. 자료에 없는 자산은 적지 않습니다(그 자산은 그 기관을 빼고 계산).
- 참고 증권사 목록은 **고정**합니다. 바꿀 때는 DECISIONS에 이유를 적습니다(결과가 좋은 곳만 고르면 편향).
- 합의 계산: 기관별 점수를 **같은 비중으로 평균**합니다(Timmermann, 2006). 평균이 0.5보다 크면 확대, −0.5보다 작으면 축소, 아니면 중립입니다(과반 원칙). 같은 자산에 `1`과 `-1`이 함께 있으면 **의견 갈림**으로 표시만 하고 결론은 평균대로 냅니다(2026-10-09 변경).

## 3. 입력 순서 (GitHub 웹, 핸드폰 가능)

1. github.com/koreanchubby/ai-pb → `data/house_view_input.json` 열기 → 연필(Edit) 버튼
2. `month`를 이번 달로 (`"2026-11"`), 처음 실제 자료를 넣을 때 `demo`를 `false`로
3. `sources`의 기관마다 채우기
   - `id`: 영문 짧은 이름(겹치지 않게, 예: `mirae`)
   - `name`: 기관명, `title`: 자료명, `published`: 발간일 `"2026-11-03"` 형식, `url`: 자료 페이지 주소(`https://`로 시작, 없으면 `null`)
   - `views`: 위 키별 `1` / `0` / `-1`
4. 아래 **Commit changes** → "Commit directly to the main branch" → Commit
5. 1~2분 뒤 Actions 탭의 **house-view**가 초록 체크면 `data/house_view.json`이 자동으로 다시 계산됩니다.
   - 빨간 X면 로그의 "입력 오류: …" 줄이 어느 칸이 틀렸는지 알려줍니다. 고쳐서 다시 커밋하면 됩니다. 입력이 틀려도 매시간 뉴스 수집은 멈추지 않습니다.
   - 반영된 결과가 사이트(`data/house_view.json`)에 보이기까지 몇 분 걸릴 수 있습니다(Pages 다시 빌드).

예시 한 곳:
```json
{
  "id": "broker-a",
  "name": "OO증권 리서치센터",
  "title": "11월 하우스뷰",
  "published": "2026-11-03",
  "url": "https://example.com/report",
  "views": {"kr_equity": 0, "global_equity": -1, "govbond": 1, "corpbond": 0, "alternative": 0, "cash": 1}
}
```

## 4. 결과 파일 (`data/house_view.json`) — 화면 연결용

| 필드 | 뜻 |
|---|---|
| `month`, `generated_at`, `demo` | 기준 월, 계산 시각, 데모 여부 |
| `sources[]` | 기관명·자료명·발간일·링크 (화면 하단 출처 표시용) |
| `consensus.<키>.view` / `label` / `tone` | 합의: `1` 확대·`0` 중립·`-1` 축소 / 표시 문구 / 기존 화면 색 이름(`buy`·`hold`·`sell`) |
| `consensus.<키>.mean`, `n`, `votes` | 평균 점수, 참여 기관 수, 기관별 점수 |
| `consensus.<키>.disagreement` | `true`면 "의견 갈림" 표시 (결론은 평균대로) |

- 지금 화면(`app.js`의 `HOUSE_VIEW`)은 고정 데모값입니다. 이 파일을 화면에 연결하는 작업은 화면 담당과 상의 후 별도 PR로 합니다. 데모 입력은 지금 화면과 같은 결론(해외 주식 축소, 국채·현금 확대)이 나오게 만들어 두었습니다.

| `lpl` | LPL Research 「Tactical Asset Allocation Guide」 | 1쪽 색 점 표 (이유경 노트북 네트워크는 차단돼 **옥경환이 받아 공유**) | 월간 |
| `ubs` | UBS 「UBS House View」 | 14쪽 오른쪽 **Asset allocation tilts**(기준 대비 조절) | 월간 |

**점수로 옮기는 규칙**
- 그 기관 척도의 **중립보다 높으면 +1, 같으면 0, 낮으면 -1**. 단기(분기·3개월) 의견 우선
- **해외 기관은 국내 주식(`kr_equity`)을 적지 않음.** 국채는 한 칸: 국내 기관 = 한국 국채, 해외 기관 = 미국·선진국 국채
- 우리 자산에 기관 자산이 여러 개 걸리면 비중이 큰 쪽(해외 주식 = 선진국/미국). **만기별로 갈리면 평균**을 내서 ±0.5를 넘을 때만 ±1
- 회사채: 국내 기관은 국내 크레딧, 해외 기관은 투자등급(IG). 하이일드는 쓰지 않음. 금·리츠: 금·리츠·귀금속 의견만(헤지펀드형 "대체투자"는 다름)
- 자료에 해당 자산이 없으면 적지 않음 (예: 신영은 국채 항목이 없어 국채 생략)
- 매달 입력 시점의 **최신본**을 쓰고, 발간 후 3개월이 지난 자료는 빼기
- 링크(`url`)는 PDF 주소가 아니라 **공개 목록·소개 페이지**. PDF·표는 저장소에 올리지 않음
