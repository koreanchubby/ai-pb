# 포트폴리오를 언제·얼마나 바꾸나 (변경 규칙)

> 상태: **옥경환 결정(2026-10-16) · 이유경 확인 대기.** 결정 기록은 `docs/DECISIONS.md` 2026-10-16 항목.
> 계산 코드(`app.js`)는 아직 바꾸지 않았습니다. 이 문서가 앞으로 구현할 기준입니다.

## 한 줄 요약

**기본은 월간 하우스뷰 때만 바꾼다. 그 밖에는 미리 정한 예외 규칙 3개로만 바꾼다. 뉴스 자체로는 바꾸지 않는다.**

## 1. 기본: 월간 하우스뷰

- 매달 참고 기관 의견을 입력하면 합의 → TAA 조정(SAA 대비 자산당 ±2%p, 주식 합계 ±3%p 이내) 계산.
- 데일리 시황·뉴스는 **기록과 설명용**이며 비중을 바꾸지 않음.

## 2. 예외 규칙 (이 3개 말고는 월중에 바꾸지 않음)

| 규칙 | 언제 | 무엇을 |
|---|---|---|
| **① 비중 이탈 리밸런싱** | 자산군 비중이 목표에서 **2%p 넘게** 벗어날 때 (예: 주식 목표 30% → 28~32%는 그대로, 27%·33%부터) | 넘은 자산만 **목표 비중으로 되돌림**. 방향은 바꾸지 않음 |
| **② 월중 하우스뷰 변경** | 참고 기관이 월중에 의견을 공식적으로 바꿔(임시 보고서·수정판) 다시 계산한 **합의 결론이 바뀔 때** (예: 확대 → 중립) | 그 자산만 TAA 다시 계산 |
| **③ 고객 사정 변화** | 은퇴, 상속 발생, 목돈 필요, 투자성향 재진단 | 처음부터 다시 설계 |

### 공통 규칙

| 항목 | 내용 |
|---|---|
| 점검 시점 | 매 영업일 **종가 기준 하루 한 번** (장중에는 반응하지 않음 → 짧은 출렁임에 사고팔기 반복 방지) |
| 횟수 제한 | **없음.** 조건을 만족할 때마다 적용 (예: 급락이 이어져 비중 이탈이 여러 번 생기거나, 종전 후 다시 전쟁이 나 기관 의견이 또 바뀌는 경우) |
| 크기 제한 | 상한은 **조정 1회당이 아니라 SAA 대비 총한도**: 자산당 ±2%p, 주식 합계 ±3%p. 의견이 여러 번 뒤집혀도 누적되지 않음 |
| 반영 | 계산은 규칙이, **실제 반영 여부는 고객이 선택** |
| 안내 | 리밸런싱안에 "목표 비중으로 되돌리는 것이며 방향 판단이 아님"과 "이번 달 몇 번째 되돌림인지"를 함께 표시 |

### 넣지 않은 것

- **"급락하면 주식을 줄인다" 같은 자동 방어 규칙은 두지 않음.** 급락 뒤 파는 규칙은 대개 바닥에서 팔게 만듦. 규칙 ①은 오히려 떨어진 자산을 목표만큼 다시 채움. 방향 전환(주식 축소)은 기관 의견이 바뀔 때(규칙 ②)만.
- **"같은 자산은 한 달에 한 번만" 같은 횟수 제한은 두지 않음.** 급락장에서 비중이 성향과 다른 상태로 방치되고, 기관 의견 변화를 못 따라가기 때문. 사고팔기 반복은 '하루 한 번 종가 점검'과 '2%p 밴드'로 막음.

## 3. 빅 이벤트 경보 (빅 뉴스 때 예외 판단 기준)

뉴스 내용(종전, 선거 결과 등)을 AI가 점수로 매기지 않고, **시장 반응과 기관 반응**으로 판단합니다. 아래 중 하나라도 해당하면 경보.

| 신호 | 경보 기준 | 받는 곳 |
|---|---|---|
| 주가 | KOSPI 또는 S&P500 **하루 ±3% 이상**, 또는 5거래일 ±7% 이상 | 한국투자증권·KRX |
| 공포지수 | **VIX 30 이상** | FRED 등 |
| 환율 | 원/달러 **하루 ±2% 이상** | 한국은행 ECOS |
| 금리 | 미 국채 10년 **하루 ±0.2%p 이상** | 한국투자증권 |
| 기관 | 참고 기관 **2곳 이상**이 임시 코멘트·의견 변경 | 하우스뷰 원문 |

**경보가 울리면 (사람 승인 없이 규칙대로)**
1. 비중은 바로 바꾸지 않음
2. 그날 종가로 규칙 ① 점검 → 2%p를 넘은 자산이 있으면 리밸런싱안을 계산해 고객에게 표시
3. 기관 의견 변화를 추적 → 합의 결론이 바뀌면 규칙 ②
4. 데일리 시황·화면에 "빅 이벤트 경보: 무엇이 얼마나 움직였는지, 내 포트폴리오에서 바뀌는 것" 표시
5. 다음 달 하우스뷰 입력 때 반영

**예시**
- 종전 소식에 유가 급락·KOSPI +3% → 경보. 주식 비중이 목표보다 2%p 넘게 커졌으면 일부를 덜어 목표로 되돌리고, 아니면 그대로.
- 선거 결과로 특정 업종만 급등 → 지수 기준을 넘지 않으면 자산군 배분은 그대로. 업종 영향은 다음 달 섹터 하우스뷰(위성, `docs/CORE_SATELLITE_PLAN.md`)에서.

**기준 숫자의 근거**: ±3%·VIX 30 등은 시장에서 흔히 쓰는 '큰 움직임' 기준이지만 지금은 **팀 판단**. 과거 데이터로 "1년에 몇 번 울리는지"를 세어 너무 자주(예: 월 1회 이상) 울리지 않게 조정하고 결과를 DECISIONS에 기록할 예정.

## 4. 데일리 시황·AI 요약 게시: 팀 승인 없음

- AI가 원문 확인 → 요약 → 규칙 검증(원문을 연 기사만, AI 이용을 막지 않은 언론사만, 지표마다 기준일)을 통과하면 **사람 승인 없이 게시**.
- 위 1~3절 때문에 시황·요약은 비중을 바꾸지 않으므로, 게시 단계에서 사람이 막아야 할 결정이 없음.
- 화면 표시는 'AI 작성 · 투자 권유 아님'. 문제가 보이면 발견한 사람이 바로 내리고 STATUS에 기록.

## 5. 하우스뷰 화면: '근거 뉴스·지표' 탭 삭제

- 방향은 월간 하우스뷰가 정하므로 결정에 쓰이지 않고, 데일리 시황 탭과 내용이 겹침.
- 대신 하우스뷰 화면에 **"이번 달 판단: 유지 / 빅 이벤트 경보 중"** 한 줄과 데일리 시황 링크만 둠.
- 하우스뷰 화면 탭은 '상세 리포트(기관별 점수)'와 '판단 기록' 두 개가 됨.
