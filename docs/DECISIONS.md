## 2026-10-03 · PWA 구성 방식

- **결정**: `manifest.webmanifest` + 서비스 워커(`sw.js`) + 등록 파일(`pwa.js`)을 **app.js와 분리**해 추가. `index.html`은 4줄(manifest·apple-touch-icon 링크 2줄, iOS meta 2줄)과 스크립트 1줄만 추가
- **근거**: 과목 결과물이 PWA(강의자료). v4에는 manifest·서비스 워커가 없어 "설치 가능한 앱" 조건을 못 채움. app.js는 공유 파일이라 충돌을 피하려고 분리
- **캐시 전략**: 모든 요청 **네트워크 우선**, 실패 시 저장본. 온라인에서는 항상 최신 파일이 보여 팀원이 CSS·JS를 고쳐도 캐시 때문에 헷갈리지 않음. 오프라인에서는 마지막 화면·뉴스 표시
- **검증**: Playwright — 설치 가능 오류 0, 오프라인 새로고침 정상, 새 버전 알림·이전 캐시 삭제 정상, 콘솔 오류 0
- **규칙**: 미리 저장할 파일 목록(`SHELL_FILES`)을 바꿀 때만 `sw.js`의 `CACHE_VERSION`을 올린다

## 2026-10-03 · 뉴스·시장 데이터 출처 선정 (이슈 #2)

- **결정**: 공개 앱에 표시해도 되는 **공식·오픈 라이선스 출처**만 사용한다. 국내 언론사 RSS는 쓰지 않는다.
- **근거**: 국내 언론 RSS는 개인 구독용으로만 제공되고 홈페이지 등을 통한 다수 공유·영리 이용을 금지함(예: 경향신문 RSS 안내). 정책브리핑(korea.kr) RSS는 서비스가 중단됨. 우리 앱은 공개 URL이므로 재게시가 허용되는 출처만 쓴다.

| 출처 | 분야 | 형태 | 비용·키 | 이용 조건 (확인 내용) |
|---|---|---|---|---|
| GDELT DOC 2.0 API | 지정학·반도체·글로벌 뉴스 헤드라인 | JSON (제목·링크·언어·날짜), 최근 3개월, 최대 250건 | 무료, 키 불필요 | 상업 포함 무제한 이용 가능, **GDELT 인용과 링크 필수** |

| 한국은행 ECOS Open API | 한국 기준금리·환율·물가 | JSON | 무료, 회원가입 시 인증키 | 저작권보호방침의 공공누리 기준 적용 — **세부 유형은 원문 재확인 필요** |

## 2026-09-30 · 하우스뷰 구성 방식

- **결정**: 국내 메이저 증권사 여러 곳의 월간 하우스뷰를 자산군별 +1 / 0 / -1로 점수화해 **동일가중 합의**로 TAA 산출
- **근거**: 여러 전망을 결합하면 개별 전망보다 평균적으로 오차가 작고, 단순 평균이 정교한 가중보다 자주 낫다는 예측 결합 연구 — Timmermann (2006), *Handbook of Economic Forecasting* Vol.1 Ch.4, 135–196 (주 근거); Bates & Granger (1969), *Operational Research Quarterly* 20(4), 451–468 (보조, 이 논문의 가중치는 오차분산 기반이라 '동일가중' 근거로는 약함). 2026-10-03 서지 확인. 한 곳만 쓰면 편향·선택 근거 설명이 어려움
- **규칙**
  - 보고서 원문·표·차트를 앱에 게시하지 않음 (증권사 저작권). 점수와 출처(기관명·자료명·발간일)만 사용
  - 참고 기관 목록은 고정 (결과 좋은 곳만 고르는 선택 편향 방지)
  - 의견이 크게 엇갈리는 자산(+1과 -1 공존)은 0 처리 후 "기관 간 의견 불일치" 표시
  - 관리자가 월 1회 수동 입력 (자동 크롤링 금지)
  - 실제 자료를 쓰기 전까지 "OO증권 리서치센터 (데모 예시)" 표기 유지
